## 文件与验证

- foundations.json、structures.json、algorithms.json：题面、测试和两种语言的维护用参考解答。参考解答只保存在仓库，导入时不发送给学生。
- 各自的 build_*.py：生成内容及确定性测试；verify_*.py：实际编译 C++ 并运行双语言参考解答及独立对拍。
- validate_curriculum.py：跨文件编号、章节数量、重复、语言、用例大小等校验。
- import_curriculum.py：只追加新题，按稳定键/完整标题去重；先记录既有全部任务内容指纹，完成后检查未被改写。导入出现中断可用同一 manifest 重试，不批量删除旧题。
- live-manifest.json：线上 ID 与验证结果；不包含密码。
- audit_cpp.py 与 *-sanitizer-report.json：逐一编译并运行固定测试，启用 C++ 未定义行为检查。
- stress_prefix.py / stress_graphs.py：另行检查题面允许的最大规模；这些本地压力数据不受线上单测试 16 KB 限制，不表示所有大规模输入均已上传 Judge0。
- cross-review-report.json：跨代理独立审阅、对拍方法及修正记录。
- release-verification.json：本次最终上线数量、内容哈希、真实 Judge0 预览结果及范围说明。

完整校验使用 validate_curriculum.py --complete，传入上述三个 JSON 文件。发布需要显式 --publish，管理员凭据从本机文件读取。默认运行导入器仅本地验证。线上抽测使用管理员预览，不产生学生作业成绩。

## 范围

本批为公开题库练习，非自动发布的作业或考试；不改动已有内部培训题、提交或阶段成绩。原有 56 道公开题库内容保留，新题按 01–12 章显示，历史阶段题保留自己的分组。

参考 SkyWalker 的“按知识点逐步刷题”组织方式，但不复制其题面、数据或参考代码。本批独立编写，与第三方题库无授权或背书关系。

维护时先验证、再固定内容、最后发布。发布后的题目不要直接重写；服务器会阻止修改已有学生作答或判题记录的题，需发布新版本保留原成绩。033 曾在本轮上线后发现与旧题目标重复，确认零作答并通过该保护接口改为帕斯卡三角形；记录见 replacement-033.json。

测试是有限抽样，并非正确性证明。本地 Python 参考程序以 3.8 语法检查，在本机实际 Python 运行时执行；报告如实记录版本。最终线上抽测使用服务器 C++ GCC 9.2 和 Python 3.8，管理员预览不产生学生成绩。
