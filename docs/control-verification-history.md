# 电控系统学习路径

本批独立编写并上线 120 道公开练习，电控公开题库从 60 道增至 180 道，沿 C 基础、C 进阶、STM32 应用逐步学习。每章 10 题；前八章各 5 道 C 编程和 5 道客观题，后四章为客观题。总计 40 道编程、31 道单选、23 道多选、26 道填空。

| 课程 | 编号 | 章节 |
| --- | --- | --- |
| C语言基础 | 001–040 | 输入输出与表达式、条件与状态判断、循环与数值处理、数组与采样序列 |
| C语言进阶 | 041–080 | 函数与模块化、指针与字符串、结构体与内存、位运算与通信数据 |
| STM32单片机基础 | 081–120 | 时钟与GPIO实践、中断与定时器应用、采样与通信外设、调试与可靠控制 |

STM32 题限定 STM32F103C8 / Cortex-M3，题面明确型号、时钟及计算条件，不将 F1 寄存器行为套用于所有 STM32。GPIO、定时器、中断、ADC、DMA、USART、I2C、SPI、看门狗与控制时序通过官方 RM0008、PM0056、DS5319、UM2237 核查。板级故障题是给定条件下的原理练习，不是硬件实测。

## 内容与验证

- `basic.json`、`advanced.json`、`stm32.json` 保存题面、答案、测试、来源和维护参考代码。
- `build_*.py` 可重建内容；`verify_*.py` 和对应报告记录实际编译、独立对拍或官方文档核查。
- `validate.py` 检查编号、题型、章节、样例、尺寸和课程标签；`--complete` 要求完整 120 题。
- `audit_c.py` 对全部 40 份 C11 参考代码启用 ASan/UBSan，运行 322 个固定用例（80 公开、242 隐藏）。本地参考解答通过不表示任何用户解答自动正确。
- `api_corpus_test.go.txt` 在生产版本后端的临时数据库中创建全量题目，验证 160 次正确/错误客观题判分、跨组练习权限和答案/隐藏用例脱敏。结果见 `api-corpus-test.log`。
- `check_online.py` 使用 Judge0 的 C 语言 50 和管理员预览核查真实在线执行，不提交学生作业。结果存于 `online-*.json`。
- `release-verification.json` 保存最终发布数量、内容哈希和线上验证结果。

C 基础通过 160 固定用例、2000 独立随机用例和 20 项 C 语义探针；C 进阶通过 162 固定用例、420 独立随机用例和 5 项客观题 C 探针。STM32 通过 15 项公式核查、40 题机制复核及 61 处官方文档文字证据检查。测试是有限抽样，不构成正确性证明。

## 导入维护

`import_bank.py` 默认仅校验；写入需显式 `--publish --complete`、管理员邮箱及本地凭据文件。凭据不写入题库和日志。内容导入只追加，按稳定键及完整标题去重，不覆盖原有题目或提交。`live-manifest.json` 记录线上 ID 和原 339 项任务的内容指纹；中途失败可以使用相同 manifest 继续，已有题先核对而非重复创建。

由于现有课程列表按创建时间倒序，本批按 120→001 导入，使各课程显示顺序从入门小题开始。三个课程标签和知识标签沿用现有界面，不需要部署应用代码。维护参考代码、客观答案与隐藏测试不作为题面暴露给学生；客观题作答后显示解析。

本批是公开题库练习，其他组成员也可刷题。作业仍由老师自行选题发布；本批不自动创建作业、考试或培训通过记录。原有 60 道电控题保留。
